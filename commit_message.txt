feat(queue): add addBulk, retryJobs and promoteJobs

Port Node bullmq@5.8 queue bulk operations:

- Queue::add_bulk adds multiple jobs in one call, reserving auto-generated
  job IDs with a single INCRBY and reusing the same delayed/prioritized/
  standard dispatch as Queue::add (extracted into a shared dispatch_add
  helper).
- Queue::retry_jobs moves failed or completed jobs back to wait by looping
  the new moveJobsToWait-8.lua script (cursor semantics identical to Node:
  iterate until the script returns 0). Defaults timestamp to now and
  rejects states other than failed/completed.
- Queue::promote_jobs promotes delayed jobs to wait using the same script
  with the 'delayed' state and Number.MAX_VALUE as timestamp, matching
  Node's promoteJobsArgs.

Adds the moveJobsToWait Lua script plus the batches and getOrSetMaxEvents
includes, registers them in the script loader, and exposes a
move_jobs_to_wait command wrapper. Covered by integration tests for mixed
add_bulk options, retrying failed jobs (including failedReason cleanup),
invalid-state rejection and multi-iteration promotion.
